# Unemployment-Visualization-Dataset
Data Visualization Project analyzing Austrian unemployment data from AMS (Arbeitsmarktservice Österreich).

## Investigations
1. **Unemployment by age group and health restrictions**
   (`age_group_bar_chart.png`, `health_restriction_line_chart.png`)
2. **Regional patterns across the Austrian federal states**
   (`b1_bundesland_flow_glyph_map.png`, `b2_heatmap.png`)

## Files
- `sub_03_intermediate.ipynb`: notebook with the analysis and code
- `Fantastic Four Visualization Presentation.pdf`: project presentation
- `Gesamtuebersicht_AL_RGS.csv.zip`: AMS dataset (unzip before use)
- `environment.yml`: software environment
